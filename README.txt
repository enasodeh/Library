How to access My code:
1. Go on Qt Creator
2. By the welcome tab tap the "Open Project"
3. Go to the place that my code is saved in your computer.
4. It will open then on the "Edit " tab, save it and then you can run the code(ctrl+R)
5. The app will pop up after you ru the code and you can add books/magazines and search.


Contents:
- libraryitem.h / libraryitem.cpp : base class
- book.h / book.cpp : Book derived class
- magazine.h / magazine.cpp : Magazine derived class
- storage.h : Template Storage<T> manager
- libraryutils.h / libraryutils.cpp : "LibraryUtils" module (utility functions)
- mainwindow.h / mainwindow.cpp : Qt GUI (programmatic, no .ui)
- main.cpp : application entrypoint
- LibraryManagement.pro : Qt project file
- sample_data/library_data.txt : example data file

Notes:
- The LibraryUtils module is included as a separate pair of files and used by the application.
- The GUI uses QListWidget for displaying items and QSortFilterProxyModel for searching.
- Tested with Qt 5 (C++11). Open the .pro file in Qt Creator and build.
